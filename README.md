Sales Data Analysis

1. Project Overview
This project focuses on analyzing sales data using Python and Power BI to understand sales performance and identify useful business insights.

2. Problem Statement
The aim of this project is to analyze sales records, identify trends, compare product and salesperson performance, and support better business decisions.

3. Dataset Description
- Dataset: Sample Sales CSV
- Total Records: 240
- Total Columns: 8
- Missing Values: 0
- Duplicate Records: 0

4. Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- GitHub

5. Data Cleaning Process
- Checked missing values.
- Checked duplicate records.
- Inspected column names and data types.
- Cleaned the dataset.
- Identified one outlier.

6. Exploratory Data Analysis (EDA)
Performed descriptive statistics, correlation analysis, product-wise sales analysis, region-wise sales analysis, and salesperson performance analysis.

7. Visualizations
Created five charts using Python:
1. Sales by Product
2. Sales by Region
3. Sales by Salesperson
4. Monthly Sales Trend
5. Sales Distribution

8. Power BI Dashboard
Created a dashboard containing KPI cards, product-wise sales, region-wise sales, salesperson performance, monthly sales trends, and a region slicer.

9. Key Insights
- Total revenue is approximately 142.44K.
- Total quantity sold is approximately 1K.
- Average unit price is 126.36.
- Product sales vary across different products.
- Monthly sales show a changing trend.

10. Business Recommendations
- Promote low-performing products through suitable offers.
- Study the practices of high-performing salespeople to improve overall performance.

11. Conclusion

This project helped analyze sales data, understand business trends, and create visual reports using Python and Power BI.
